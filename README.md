# 🎨 Digital Art Selling Platform

## 📝 Project Description

This is a web-based platform designed to help artists showcase and sell their hand-painted and handcrafted artworks. The platform allows users to register, post their artworks, update or delete them, and manage their profiles. Admins can manage categories, user content, and system roles. The application also includes Google authentication and PayHere payment integration (currently in progress).
